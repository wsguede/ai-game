# v2.2 Tech — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four tiers of market intelligence to the shop, progressively revealing price direction, magnitude, and historical context, while removing the always-visible trend arrows from the base game.

**Architecture:** `Market.getTechIntel()` computes an intel object per candy; `UI.renderMarket()` renders it. `state.priceHistory` records the base market price for each candy every turn from day 1. Shop data adds a `tech` category alongside `storage`. `Shop.purchase()` is made category-agnostic so it doesn't force-set `stashCapacity` for non-storage items.

**Tech Stack:** Vanilla JS (IIFE + window globals), HTML/CSS inline in `index.html`, Vitest for unit tests.

- [ ] **Step 3: Implement `getTechIntel` in `src/engine/market.js`**

Add the following function inside the `Market` IIFE, before the `return` statement:

```js
  // Computes market intelligence display data for a candy at a given tech tier.
  // candy:          candy object from ERA_V1.candies
  // currentBasePrice: currentPrices[candy.id] — raw market price before location modifier
  // prevSeenPrice:  previousSeenPrices[candy.id] — last location-adjusted price the player saw
  // locPrice:       current location-adjusted price the player sees this turn
  // techTier:       0–4 (state.ownedTiers.tech)
  // priceHistory:   state.priceHistory — { [candyId]: number[] } of base market prices
  // Returns: { arrowClass, hlLabel, tooltip }
  function getTechIntel(candy, currentBasePrice, prevSeenPrice, locPrice, techTier, priceHistory) {
    if (techTier === 0) return { arrowClass: null, hlLabel: null, tooltip: null };

    var pct = prevSeenPrice > 0 ? (locPrice - prevSeenPrice) / prevSeenPrice : 0;
    var arrowClass;
    if (techTier >= 2) {
      if      (pct >  0.05) arrowClass = 'upup';
      else if (pct >  0)    arrowClass = 'up';
      else if (pct < -0.05) arrowClass = 'downdown';
      else if (pct <  0)    arrowClass = 'down';
      else                  arrowClass = 'flat';
    } else {
      if      (pct > 0) arrowClass = 'up';
      else if (pct < 0) arrowClass = 'down';
      else              arrowClass = 'flat';
    }

    if (techTier < 3) return { arrowClass: arrowClass, hlLabel: null, tooltip: null };

    var history = priceHistory[candy.id] || [];
    if (history.length < 3) return { arrowClass: arrowClass, hlLabel: null, tooltip: null };

    var low   = Math.min.apply(null, history);
    var high  = Math.max.apply(null, history);
    var range = high - low;

    var hlLabel = null;
    if (range > 0) {
      var third = range / 3;
      if      (currentBasePrice <= low  + third) hlLabel = 'LOW';
      else if (currentBasePrice >= high - third) hlLabel = 'HIGH';
      else                                        hlLabel = 'MID';
    }

    var sum = history.reduce(function(acc, p) { return acc + p; }, 0);
    var avg = Math.round(sum / history.length * 100) / 100;

    var tooltip;
    if (techTier === 3) {
      tooltip = { avg: avg };
    } else {
      var vsAvgPct = avg > 0 ? Math.round((currentBasePrice - avg) / avg * 100) : 0;
      tooltip = {
        avg:       avg,
        low:       Math.round(low  * 100) / 100,
        high:      Math.round(high * 100) / 100,
        vsAvgPct:  vsAvgPct,
      };
    }

    return { arrowClass: arrowClass, hlLabel: hlLabel, tooltip: tooltip };
  }
```

          ? '<span style="color:#aaa">' + next.capacity + ' slots</span>'
          : '';
        html +=
          '<div style="margin-bottom:4px">' +
            '<div style="display:flex;justify-content:space-between;margin-bottom:4px">' +
              '<span style="color:#ffdd00">' + next.name + '</span>' + detail +
            '</div>' +
            '<p style="color:#888;font-size:11px;margin-bottom:8px;line-height:1.5">' + next.flavor + '</p>' +
            '<div style="display:flex;justify-content:space-between;align-items:center">' +
              '<span style="color:' + (canAfford ? '#4cff72' : '#ff4444') + '">$' + next.price + '</span>' +
              '<button class="action-btn" ' +
                (canAfford ? 'onclick="Game.buyTier(\'' + category + '\')"' : 'disabled') +
              '>BUY</button>' +
            '</div>' +
          '</div>';
      }
      html += '</div>';
    });

    document.getElementById('shop-content').innerHTML = html;
    document.getElementById('shop-modal').classList.add('active');
  }

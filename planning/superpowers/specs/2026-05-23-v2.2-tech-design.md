# v2.2 Tech — Design Spec

**Date:** 2026-05-23
**Branch:** `feat/v2.2-tech`

## Overview

v2.2 adds a **tech** category to the shop: four tiers of market intelligence that progressively reveal more price information. The base game loses its trend arrows entirely — direction becomes the first thing you buy.

The theme is a student manually tracking candy prices with increasingly powerful tools: scribbled notes → calculator → school computer → computer lessons.

---

## Tier Definitions

| Tier | Name | Arrow rendering | Tag | Hover tooltip |
|---|---|---|---|---|
| 0 | (none) | none — price only | none | none |
| 1 | Pen & Paper | ▲ / ▼ / — (single arrow) | none | none |
| 2 | Calculator | ▲▲ / ▼▼ when >5%, else ▲/▼/— | none | none |
| 3 | Computer Access | same as T2 | HIGH / MID / LOW | avg price |
| 4 | Computer Lessons | same as T2 | HIGH / MID / LOW | avg + seen low + seen high + % vs avg |

**Arrow thresholds:**
- T1: any upward move → ▲, any downward → ▼, flat → —
- T2: move >5% → double arrow (▲▲ / ▼▼); ≤5% → single arrow; flat → —

**HIGH / MID / LOW thresholds:** based on the candy's all-time seen price range (global, not per-location). Bottom third of range = LOW, top third = HIGH, middle third = MID. Suppressed until the candy has at least 3 history entries.

**Hover tooltip contents:**
- T3: `avg price: $X.XX`
- T4: `avg price: $X.XX · seen low: $X.XX · seen high: $X.XX · vs avg: ±N%`

---

## Price History

**What is tracked:** the base market price (`currentPrices[candyId]`) for each candy — global, before any location modifier is applied.

**State field:** `priceHistory: { [candyId]: number[] }` — one array per candy, appended every turn.

**When updated:** at the end of `advanceTurn()` in `game.js`, after `Market.updatePrices()` runs.

**Tracking starts:** turn 1, always — regardless of what tech tier the player owns. Buying Computer Access on day 60 immediately shows 60 turns of history.

## Module Changes

### `src/engine/market.js` — new public function

```js
getTechIntel(candy, prevPrice, techTier, priceHistory)
// Returns: { arrowClass, hlLabel, tooltip }
```

| Field | Type | Values |
|---|---|---|
| `arrowClass` | string \| null | `null`, `'flat'`, `'up'`, `'down'`, `'upup'`, `'downdown'` |
| `hlLabel` | string \| null | `null`, `'HIGH'`, `'MID'`, `'LOW'` |
| `tooltip` | object \| null | `null` · `{ avg }` (T3) · `{ avg, low, high, vsAvgPct }` (T4) |

The existing `getPriceTrend` is **not modified** — it remains in use for the debug price breakdown tooltip.

**`hlLabel` computation:**
```
history = priceHistory[candy.id] || []
if history.length < 3 → hlLabel = null
low  = min(history)
high = max(history)
range = high - low
third = range / 3
if currentPrice <= low + third  → 'LOW'
if currentPrice >= high - third → 'HIGH'
else                            → 'MID'
```

### `src/engine/ui.js` — `renderMarket`

Receives `techTier` as a new parameter (passed from `Game.render()` via `state.ownedTiers.tech`).

For each candy row, calls `Market.getTechIntel()` and renders:
- **T0:** `$1.20` — plain price, no arrow
- **T1:** `$1.20 ▲` — single arrow, no tooltip on price cell
- **T2:** `$1.20 ▲▲` — single or double arrow, no tooltip on price cell
- **T3:** `$1.20 ▲▲ [HIGH]` — tag inline; hover on price cell shows avg tooltip
- **T4:** `$1.20 ▲▲ [HIGH]` — tag inline; hover on price cell shows full intel tooltip

The existing `trend-tip` hover (showing `% vs last seen`) is removed at T0. At T1 and T2 it remains on the arrow element, showing the percentage change vs last seen. At T3/T4 the intel tooltip replaces it on the price cell — the arrow's own hover is removed to avoid two competing tooltips.

### `src/engine/game.js` — `advanceTurn()`

After `Market.updatePrices()`:
```js
era.candies.forEach(function(c) {
  if (!_state.priceHistory[c.id]) _state.priceHistory[c.id] = [];
  _state.priceHistory[c.id].push(_state.currentPrices[c.id]);
});
```

`Game.render()` passes `state.ownedTiers.tech` to `UI.render()`, which forwards it to `renderMarket`.

### `src/engine/shop.js`

The existing shop purchase handler reads `SHOP.tech` and updates `ownedTiers.tech` — no structural change needed beyond adding the data entry.

## Testing

New tests in `src/tests/` (Vitest):

**`Market.getTechIntel`:**
- T0 → all nulls
- T1 → correct `arrowClass` for up / down / flat; `hlLabel` and `tooltip` null
- T2 → `upup` / `downdown` when change >5%; single arrow when ≤5%
- T3 → `hlLabel` set when history ≥ 3 entries; `tooltip.avg` correct; `hlLabel` null when history < 3
- T4 → full tooltip: `avg`, `low`, `high`, `vsAvgPct` all present
- HIGH/MID/LOW boundary values: value at exactly the third boundary goes to correct bucket

**`State` / `Game`:**
- `priceHistory` is populated after `advanceTurn()` for each candy
- `ownedTiers.tech` initialises to 0
